# @deepseek-ai/dsh-client-locale-ru

English | [中文](README.zh.md)

## Summary

This package adds Russian as a selectable interface language without touching the dictionaries each feature package owns. It registers the `ru` language plus one dictionary per namespace, so a Russian browser starts in Russian and English remains the per-key fallback. It contributes browser copy only and never reaches a model request.

<a id="use-this-package"></a>
## Use this package

Mount the package in the browser roster of a deployment that serves Russian-speaking users. It has no configuration: the language appears in the Language row, a browser requesting `ru` selects it automatically, and every registered namespace resolves Russian copy with English fallback for keys the pack does not translate.

Leave the package out when the deployment ships its own translation source; nothing else changes, since the pack only adds a language and per-namespace dictionaries.

<a id="understand-the-implementation"></a>
## Understand the implementation

<details>
<summary>Implementation internals — click to expand</summary>

[`src/client/dicts.ts`](src/client/dicts.ts) is generated by `custom/scripts/extract-locale-ru.mjs` from the pinned upstream tag recorded as `RU_LOCALE_REF`, together with the namespace-to-dictionary-file map the coverage test reads. [`src/client/overrides.ts`](src/client/overrides.ts) carries keys this fork renders that upstream does not translate yet, and survives regeneration. [`src/client/dictionaries.ts`](src/client/dictionaries.ts) merges both, and [`src/client/index.ts`](src/client/index.ts) registers the language and each namespace as owned effects, so disposing the plugin withdraws the language and frees every `ru` slot.

The coverage test fails when an English key has no Russian entry, when a `{placeholder}` set drifts, and when the in-tree dictionaries begin exporting Russian themselves — the signal that an upstream release has made this pack redundant.

</details>

## Model Experience

None, as the package contributes browser copy only; nothing here reaches a model request.

#### KV Cache effect

None; this package neither assembles nor sends a provider request.

## Known Limitations and Deferred Work

<a id="known-limitations-and-deferred-work"></a>

- **Temporary until upstream releases** — the dictionaries come from an unreleased upstream tag; when a release ships Russian in-tree, delete this package in the same change that merges it.
- **No plural forms** — copy follows the upstream translations verbatim rather than a locale-aware plural rule.
