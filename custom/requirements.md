| A-15 | appId 采用反向域名，如 `com.<品牌>.dsh` | 需你的域名；首版发布前冻结 | 建议 |

> **appId 冻结是什么意思**：appId（macOS 的 Bundle Identifier / Windows 安装器的应用标识）是应用在操作系统和更新器里的“身份证”，不是界面上显示的名字。它决定：
> - 安装/升级时系统认不认为是同一个应用（Windows 的注册表卸载项、macOS 的 LaunchServices）；
> - 用户数据目录（Electron `userData`）、系统权限（麦克风/辅助功能）、钥匙串条目的归属；
> - 自动更新能否把新版本“覆盖”到旧版本上。
>
> 首版对外发布后改 appId，等于换了一个身份证：新版本会被当成另一个应用安装，旧版本不会被替换，数据和权限也不继承，更新链就断了。内部测试阶段随便改；对外首版前必须定死。显示名（productName）可以后改，但也会影响数据目录，建议一起冻结。

## 3. 功能需求与验收标准

### 3.1 A 品牌

| ID | 需求 | 验收（Given-When-Then） |
|---|---|---|
| A-01 | 侧边栏显示自有 Logo 与字标 | Given 启动 Web/桌面，When 首屏加载，Then 侧栏为自有品牌，fallback 不再是鱼标 |
| A-02 | 全局无官方品牌残留 | Given 构建产物，When 扫描 `packages apps`，Then 除 LICENSE/NOTICE/出处说明外无 `DeepSeek Harness` |
| A-03 | 桌面壳品牌 | Given 安装包，When 打开，Then 应用名、Dock/任务栏图标、关于面板、窗口标题均为自有品牌 |
| A-04 | 首启引导 | Given 全新安装，When 首次启动，Then 欢迎页与引导文案为自有品牌（可关闭内置引导改用自有页） |
| A-05 | 文档标题与 PWA | Given Web 页面，When 查看标签页/添加到桌面，Then 标题与 manifest 名称为自有品牌 |

### 3.2 B 登录

| ID | 需求 | 验收 |
|---|---|---|
| B-01 | 注册 | Given 未注册手机/邮箱，When 在 `/dsh/authorize` 注册，Then 可完成注册并回到 DSH 登录成功 |
| B-02 | 登录持久化 | Given 已登录，When 重启 DSH，Then 仍为登录态（token 未过期） |
| B-03 | 过期重登 | Given token 失效，When 发消息，Then 提示重新登录，重登后恢复 |
| B-10 | 本地参考实现 | Given `services/relay` 与 NewAPI，When 按 README 启动，Then E-01～E-05 通过 |
| B-04 | 登出 | Given 已登录，When 点登出，Then 本地清除且中转站 token 失效 |
| B-05 | 取消登录 | Given 登录页，When 取消/关闭，Then DSH 回到未登录态，不残留半登录 |
| B-06 | 推理 | Given 已登录，When 发一条消息，Then 流式返回；工具调用正常 |
| B-07 | 错误提示 | Given 中转站 401/429/5xx，When 请求失败，Then 分别提示重登/限流/服务错误，不暴露原始报文 |
| B-08 | 模型目录 | Given 已登录，When 打开模型选择器，Then 能看到中转站 `/models` 返回的模型；未实现的模型不可选 |
| B-09 | 多设备/吊销 | Given 账号在另一设备登录或改密，When 当前设备发请求，Then 按既定策略失效并提示重登 |

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 安全 | 全链路 HTTPS；PKCE；state 单次；token 不落日志；发布产物签名 |
| 隐私 | 关闭上游遥测；隐私说明列明中转站收集的数据 |
| 性能 | 登录 ≤3s（不含用户输入）；RTL 切换无整页重载 |
| 可维护 | 上游改动集中在 `packages/ext/*` 与 ≤30 行/文件的补丁；每次升级可 diff |
| 可回滚 | 每个里程碑有 tag；桌面更新失败可回退上一版 |
